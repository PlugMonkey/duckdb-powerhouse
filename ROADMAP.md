# Roadmap

Current plans for DuckDB Powerhouse. Priorities may shift based on community feedback.

## Completed

- [x] Core query execution with Cmd+Enter / Ctrl+Enter
- [x] Schema explorer (databases, schemas, tables, columns)
- [x] File querying (Parquet, CSV, TSV, JSON, JSONL, NDJSON)
- [x] Remote connections (MotherDuck, PostgreSQL, S3)
- [x] Results panel with sorting, pagination, and export
- [x] SQL autocomplete for tables, columns, and keywords
- [x] 20+ SQL snippets for common DuckDB patterns
- [x] Context menus for tables, columns, and data files
- [x] Query history with persistence across restarts
- [x] Copy SQL button in results panel
- [x] Table operations (rename, drop, truncate, export)
- [x] Import data from files and URLs

## Planned

- [ ] Basic visualizations (charts from query results)
- [ ] AI-powered SQL suggestions (Premium)
- [ ] Notebook-style query editing
- [ ] Database diff and migration tools
- [ ] Query performance profiling
- [ ] Collaborative query sharing

## Feature Requests

Have an idea? [Open an issue](https://github.com/PlugMonkey/duckdb-powerhouse/issues) and tag it with `enhancement`.
